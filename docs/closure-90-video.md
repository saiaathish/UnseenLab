## Photosynthesis label conflict — resolution

The canonical trust policy (`docs/trust-policy.md`, frozen for red-team,
created 2026-08-05) classifies photosynthesis as **Level 3
`explanatory_animation`** on BOTH the hosted and offline paths, and
explicitly flags the old demo-script Beat 9 "Conceptual demonstration"
badge as the artifact in error (the beat showed the timeline
representation, which only Level 3 specs carry). Supporting evidence:
`docs/demo-benchmark.md` (Gate 2) recorded the photosynthesis gold
returning `explanatory_animation`; `docs/scientific-trust.md` defines the
three trust levels; the offline router maps "photosynthesis" to the
energy-transfer timeline (Level 3 by `TRUST_BY_KIND`).

The Phase-9 beat literally says "show Conceptual Demonstration label".
Asserting that badge on the photosynthesis card would mislabel the
verified output. Resolution: Beat 11 shows the badge as rendered with
conditional narration — expected badge "Explanatory animation" (canonical
Level 3); if the card renders "Conceptual demonstration" (the currently
flagged offline misroute), the alternate line describes that badge
truthfully. Either way the spoken line ends with the verified boundary
that the badge never reads "Verified simulation" for this spec. The video
can therefore never mislabel a spec, whichever badge the live generation
produces. Recording note in the script forbids restyling or re-entering
the card.
