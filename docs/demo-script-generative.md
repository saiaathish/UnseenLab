## Beat 1 — 0:00–0:18 · Learner problem

On the homepage: *"Every learner hits the same pre-built page. The
question I ask rarely matches the lesson I get."*

## Beat 2 — 0:18–0:32 · Ask for orbital concept

Type into the ask box as you say it: *"Show why planets stay in orbit."*

## Beat 3 — 0:32–0:48 · Hosted AI composition + trust label

Click **Generate demonstration**; say the mandated pitch line. Add:
*"The AI writes a bounded specification — never code, never the
simulator. Every spec passes a strict validator and a science policy
before anything renders."*

Summary card appears (~10 s): point at the **"Verified simulation"** badge
and the **"Generated by the demonstration model"** source badge. Click
**Enter demonstration**.

## Beat 4 — 0:48–1:05 · Prediction gate

Predict first: the prediction panel gates the controls — pick an option,
submit. *"The prediction is never graded by the model — only curated
engine code knows the answer."*

## Beat 5 — 1:05–1:30 · Manipulate launch speed

Controls unlock. Raise **Orbital speed** (one-variable mode holds the
rest). Point at the **live readouts**: *"Period 115.4 s → 180.0 s — it's
an engine readout, not a number the model wrote."*

## Beat 6 — 1:30–1:48 · 3D/2D/table canonical agreement

Open the **table** representation: the same Period value, engine-owned.
Open the **3D** tab: *"The 3D view is driven by the same engine state;
the readouts are canonical. No copy of the science lives in the
graphics."*

## Beat 7 — 1:48–2:05 · Bounded adaptation

Accept the one-variable-mode suggestion; note the **"Held constant"**
labels. *"The AI adapts the path — it never changes the physics."*

## Beat 8 — 2:05–2:20 · Revised prediction + replay

Reset, change a different variable, make a revised prediction, submit;
**Replay** restores the parameters honestly (fresh run, labeled).
*"Replay restores the same engine state — one source of truth."*

## Beat 9 — 2:20–2:37 · Conceptual photosynthesis example

Go back, ask: *"Show how photosynthesis transfers energy."* Summary card:
point at the **"Conceptual demonstration"** badge and the visible
limitation line (qualitative scope — no numbers invented). Enter; show
the timeline representation. *"Verified simulation — the engine is the
truth. Conceptual — clearly labeled, never presented as measured
physics."*

## Beat 10 — 2:37–2:50 · Participant evidence and revision

*"A learner session asks one question — why planets remain in orbit —
and exactly one product revision comes from what they actually did."* If
the session has not run yet, say exactly: *"The participant session runs
before submission; the single revision it causes is recorded in
`validation-pack/revision-log.md` — no change is invented."*

## Beat 11 — 2:50–3:00 · Closing claim

*"Every AI-generated demonstration runs through a validator, a science
policy, and a deterministic renderer. The AI composes the path to the
science — the science stays the science."* Echo the mandated pitch.

## Fallback lines (exact language, prepared)

- **Model fallback / flag off:** *"The ask flow still works — this one is
  built from the verified offline catalog."* (badge: **"Built from the
  offline catalog"**)
- **Slow generation:** *"The model is still writing a bounded spec — it
  usually takes about ten seconds. Every request is time-boxed and
  retried once, then the catalog takes over."*
- **WebGL failure:** *"This browser can't render the 3D stage, so we show
  the same engine state as a 2D stage and table — nothing about the
  science changes."*
- **Mongo unavailable:** *"Saving to your account is paused right now —
  your work still saves on this device."*
- **Firebase unavailable:** *"Sign-in is paused right now — guest mode
  still works and saves on this device."*
- **No participant result:** see Beat 10 exact language.
- **Demo refresh:** *"A reload restores it — verified."*
