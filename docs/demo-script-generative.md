## Beat 1 — 0:00–0:18 · Problem

Homepage on screen. *"Every learner hits the same pre-built page. The
question I ask rarely matches the lesson I get."* (Static explanations
fail learners who need interaction — say one sentence on that, then move
to the ask box.)

## Beat 2 — 0:18–0:33 · Type the orbital-mechanics request

Type into the ask box as you say it: *"Show why planets stay in orbit."*
(Canonical text — same string used in
`validation-pack/participant-test-extension.md` and the benchmark golds.)
Pause on the completed sentence so the viewer can read it.

## Beat 3 — 0:33–0:48 · Hosted AI composes a bounded specification

Click **Generate demonstration**; say the mandated pitch line verbatim:
*"UnseenLab lets AI compose the learning experience, but never lets AI
invent the science."* Then: *"The AI writes a bounded specification —
never code, never the simulator. Every spec is validated and checked
against the science policy before anything renders."*

The summary card appears after roughly ten seconds (p50 10.9 s,
verified). Do NOT talk over the wait; let the spinner carry it, or use
the slow-generation fallback line if it exceeds ~20 s.

## Beat 4 — 0:48–1:02 · Verified Simulation label and limitation

Point at the **"Verified simulation"** badge and the **"Generated by the
demonstration model"** source badge on the card. Then point at the
limitation lines: *"The label means curated engine code — and the card
is honest about what it does not model: idealised point-mass gravity, no
planet sizes, no collisions."* (That limitation text is the shipped
orbits limitation: "Idealized point-mass gravity; no planet sizes or
collisions are modeled.") Click **Enter demonstration**.

## Beat 5 — 1:02–1:18 · Learner predicts before controls unlock

*"Predict first — the prediction panel gates the controls."* Pick an
option, submit. *"The prediction is never graded by the model — only
curated engine code knows the answer."* (correctIndex is engine-asserted;
the model's copy is stripped with a repair label — verified.)

## Beat 6 — 1:18–1:38 · Raise launch speed

Controls unlock. Raise **Orbital speed** (one-variable mode holds the
rest). Point at the **live readout**: *"Period 115.4 s → 180.0 s — an
engine readout, not a number the model wrote."*

## Beat 7 — 1:38–1:52 · Show matching 3D, 2D, and readout state

Open the **3D** view, then the **2D** view, then the **table**: *"The 3D
view, the 2D view, and the readout are driven by the same engine state —
the readout is canonical. No copy of the science lives in the
graphics."*

## Beat 8 — 1:52–2:08 · Accept a bounded adaptation

Accept the one-variable-mode suggestion; note the **"Held constant"**
labels. *"The AI adapts the path — it never changes the physics."*

## Beat 9 — 2:08–2:22 · Revise prediction and show replay

Reset, change a different variable, make a revised prediction, submit;
**Replay** restores the parameters honestly (fresh run, labeled).
*"Replay restores the same engine state — one source of truth."*

## Beat 10 — 2:22–2:38 · Generate photosynthesis

Go back, type: *"Show how photosynthesis transfers energy."* Click
**Generate demonstration**; when the card appears, click **Enter
demonstration** and show the timeline representation. Say nothing about
the badge in this beat — the label is shown next.

## Beat 11 — 2:38–2:49 · Trust label on the photosynthesis card

Point at the badge and the visible limitation line. The badge is the one
the system rendered — NEVER restyle, relabel, or re-enter. Narration is
conditional on what the card actually shows:

- If the badge reads **"Conceptual demonstration"**: *"Conceptual
  demonstration — clearly labeled, qualitative, no invented numbers. It
  is never presented as measured physics."*
- If the badge reads **"Explanatory animation"**: *"Explanatory
  animation — a labeled narrative with accessible text, no simulation,
  no invented numbers."*

Either way, close with the verified boundary: *"The badge always shows
the true trust level — and it can never say 'Verified simulation' for a
spec like this one."* (Trust escalation is impossible — `specMatchesIntent`
in the generation pipeline; a biological process is explicitly permitted
to downgrade, never to upgrade.)

> Recording note (claim safety): the canonical trust policy
> (`docs/trust-policy.md`, section 3) classifies photosynthesis as Level 3
> `explanatory_animation` on BOTH paths and flags the old "Conceptual
> demonstration" badge copy as the artifact in error; the hosted
> benchmark recorded this exact prompt returning `explanatory_animation`.
> The video therefore must not promise which badge appears. The expected
> badge is "Explanatory animation"; if the card renders otherwise, speak
> the matching line. Shoot what renders; never restyle or re-enter the
> card. This is the Phase-9 "show Conceptual Demonstration label" beat
> resolved so the video never mislabels a spec.

## Fallback lines (exact language, prepared)

- **Model fallback / flag off:** *"The ask flow still works — this one is
  built from the verified offline catalog."* (badge: **"Built from the
  offline catalog"**)
- **Slow generation:** *"The model is still writing a bounded spec — it
  usually takes about ten seconds. Every request is time-boxed and
  retried once, then the catalog takes over."*
- **WebGL failure:** *"This browser can't render the 3D stage, so we show
  the same engine state as a 2D stage and table — nothing about the
  science changes."*
- **Mongo unavailable:** *"Saving to your account is paused right now —
  your work still saves on this device."*
- **Firebase unavailable:** *"Sign-in is paused right now — guest mode
  still works and saves on this device."*
- **No participant result:** see Beat 12 exact language.
- **Demo refresh:** *"A reload restores it — verified."*
